THE GAP

An agent wallet has no KYC file, no jurisdiction, and no one to subpoena.

Issuers

Tokenized treasuries, funds, and equities enforce holder eligibility at transfer time. An autonomous agent fits none of the checks — so today the choice is block all agents, or hope.

Operators

Teams whose agents manage real value can't prove who stands behind a wallet, under what authority it acts, or that it can be shut off. Doors stay closed.

Regulators

Stablecoin and tokenization rules are converging on entity-level accountability for automated actors. "Who is behind this wallet?" is becoming an examiner's question.

THE PROTOCOL

Verify the operator. Attest the agent. Enforce the policy.

I

Verify

The agent's operator — a legal entity — passes KYB and sanctions screening. Documents and identities stay off-chain, in the verification layer, always.

II

Attest

A passing agent receives a revocable attestation on Base via the Ethereum Attestation Service, carrying only what a counterparty needs: verified · jurisdiction · accredited. No personal data touches the chain.

III

Enforce

Issuers set policy per token — allowed jurisdictions, accreditation, transfer caps — and their token calls the Custos gate in its transfer hook. Non-compliant transfers revert with a machine-readable reason. Revocation takes one call and holds on the next transfer.

FIRST PRINCIPLES

Built the way compliance infrastructure has to be built.

No PII on-chain. Ever.

Attestations carry booleans, a jurisdiction code, and identifiers. Erasure requests stay compatible with an immutable ledger because there is nothing personal to erase from it.

Non-custodial by construction.

Custos never holds funds or customer keys. It is a software provider, not a money transmitter — a property preserved religiously.

Fail closed.

No active policy means no permitted transfers. Unknown, expired, or revoked credentials block. A verification provider error rejects — it never silently passes.

One audit trail.

Every decision — off-chain checks and on-chain enforcement — lands in a single exportable record, reconstructable from the chain and the database independently.

PROOF, NOT PROMISES
