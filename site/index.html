// the issuer integration, in full
function _update(
    address from,
    address to,
    uint256 value
) internal override {
    if (from != address(0) && to != address(0)) {
        require(
            gate.checkAndLog(to, address(this), value),
            "CUSTOS_BLOCKED"
        );
    }
    super._update(from, to, value);
}

08 First principles

Built for the moment
the demo becomes infrastructure.

01

No PII on-chain. Ever.

Only minimum eligibility attributes and identifiers enter attestations. Documents remain with the verification provider.

02

Fail closed by default.

Unknown, missing, expired, revoked, or unreadable state denies the action. Provider failure never becomes permission.

03

Core infrastructure is non-custodial.

The credential, mandate, authorizer, and gate never hold customer keys. Settlement remains an explicit venue boundary.

04

Exit cannot become confiscation.

New risk can stop immediately while controlled exits route restricted proceeds to an eligible recipient or redemption path.
