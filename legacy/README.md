# Archived Custos prototype

This directory preserves the pre-pivot Custos KYA/x402 payment experiment for
historical context. It explored portable credentials, endpoint middleware, and
transaction risk scoring.

It is **not** the current product, is excluded from the root workspace, and must
not be used for current integration, architecture, evidence, roadmap, or company
claims.

The current product is the regulated-asset settlement gate for autonomous
wallets. Start with [`../docs/PRODUCT.md`](../docs/PRODUCT.md),
[`../README.md`](../README.md), and the implementation under `../contracts/`,
`../api/`, `../sdk/`, and `../dashboard/`.
